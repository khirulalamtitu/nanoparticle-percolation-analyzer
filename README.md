# Nanoparticle Percolation Analyzer

This repository contains a Python script that segments nanoparticles from microscopy images and identifies percolation paths.  
It outputs four key visualizations:
1. Original image  
2. Full topology of nanoparticle network  
3. Individual percolating chains  
4. Shortest percolation path  

Developed using `scikit-image`, `numpy`, and `matplotlib`.

---

### Usage
Edit the `IMAGE_PATH` variable in the script to your image file location and run the `.py` file with Python 3.12 in PyCharm.
